# Public datasets for open-set authorship verification on short, informal, Romanised/code-mixed Assamese text

Scope note on method: a general web-search tool was not available in this session, so findings were gathered via Bing (through a browser pane), the Hugging Face datasets API, the arXiv API, direct fetches of ACL Anthology / Mendeley Data / GitHub / Wikimedia dumps. Semantic Scholar (HTTP 429), dblp API (bot-blocked), Mojeek (403) and DuckDuckGo (CAPTCHA — not attempted further) were unreachable, so coverage of the paywalled Springer/IJISAE/JISEM literature is thin and is flagged in Gaps.

Marking convention: **[ASSAMESE]** = Assamese-language resource; **[TRANSFER]** = other language, candidate transfer/pre-training data.

## Which Assamese text corpora preserve author or user identity?

### Takeaway
Exactly one openly downloadable Assamese corpus is explicitly author-labelled: the 16-author **AAALC** literary corpus on Mendeley Data (CC BY 4.0) — prose, not short informal text. No Assamese social-media corpus found preserves user identity: the Romanised/code-mixed Assamese collections that do exist (AssameseBackTranslit, AS-EMO, Kalita & Saharia's Facebook corpus) are released or described without author/user IDs, and the largest of them is not released publicly at all. The core gap in the assignment (≥100 authors, multiple sessions, short informal messages) is **unfilled by any resource located**.

### Cited Findings
- **[ASSAMESE] AAALC — "Assamese Authorship Attribution Language Corpora"**, Mendeley Data, DOI 10.17632/m24w2n2jtb.3, version 3 published 16 Sep 2024. 16 authors ("prominent poets, writers, and novelists from the Assamese community"); content is **novels, articles and short stories**, modern and historical; built by scraping online repositories, converting with Python libraries and OCR, merging to CSV with automatic annotation. Licence **CC BY 4.0**, open "Download All". Contributor: Smriti Priya Medhi (Gauhati University; Assam Don Bosco University). No related publication listed on the record; the page does not state document or word counts, nor script explicitly — [Mendeley Data](https://data.mendeley.com/datasets/m24w2n2jtb/3)
- A Springer book chapter, "Design and Development of a Robust Assamese Language Dataset …", is indexed as focusing on "the design and development of a linguistic corpus to address the task of author attribution" of Assamese; a second Springer chapter, "Authorship Attribution for Assamese Language Documents", reports "initial experimental results of author identification done on a manually collected" corpus (Apr 2024). Both are behind Springer; abstracts were only visible as search snippets — [Bing results index](https://www.bing.com/search?q=Assamese+authorship+attribution+corpus+dataset+16+authors)
- **[ASSAMESE] AssameseBackTranslit** (Baruah, Sanasam Ranbir Singh, Priyankoo Sarmah), LREC-COLING 2024, pp. 1627–1637: **60,312 Roman–native parallel transliterated sentences** of Assamese **social media text collected from Facebook, Twitter (now X) and YouTube**. The paper page states no dataset download URL or licence, and does not report the number of contributing users — [ACL Anthology](https://aclanthology.org/2024.lrec-main.143/)
- **[ASSAMESE] AS-EMO** (GitHub, `ponpritomboruah/Assamese-Code-Mixed-Emotion-Classification`, last touched Aug 2026): **4,502 social-media posts** (3,601 train / 901 test, seed 42) over 7 emotion classes, from **Facebook, WhatsApp and YouTube**; covers Assamese native script, Roman-transliterated Assamese, English and code-mixed combinations, plus emoji. Repository licence **MIT** (code); artefacts of an M.Tech project "Emotion Classification in Regional Code-Mixed Text using Zero/Few-Shot Learning". The README has a "Dataset and Privacy" section, but its body was not retrievable in either the rendered page or the raw README fetch, so the anonymisation policy and any user-ID handling could not be verified; no author/user count is stated — [GitHub repo](https://github.com/ponpritomboruah/Assamese-Code-Mixed-Emotion-Classification); [raw README](https://raw.githubusercontent.com/ponpritomboruah/Assamese-Code-Mixed-Emotion-Classification/main/README.md)
- **[ASSAMESE] Assamese–English code-mixed social text** (GitHub, `nayanjk12/assamese-english-codemixed-dataset`): single file `English_Assamese.txt`, **26,444 words / 5,977 unique tokens**, harvested from **Facebook groups and pages**; **no licence file or licence statement**; no indication of usernames or poster metadata. Publication: Kalita & Saharia, "Language identification on code-mix social text", Proc. Int. Conf. on Computing and Communication Systems, Springer 2018, pp. 433–440 — [GitHub repo](https://github.com/nayanjk12/assamese-english-codemixed-dataset)
- **OSINT Group, IIT Guwahati** is indexed by Bing as having a resources page at `https://www.iitg.ac.in/cseweb/osint/resources.php`, described as researching "topic modeling, event detection, sentiment analysis, speech …"; the group also runs a YouTube channel showing an "Assamese Sentiment Annotation Tool Demo". **Both `/cseweb/osint/resources.php` and `/cseweb/osint/` returned HTTP 404 on 31 Oct 2026**, so no resource inventory or access terms could be read — [Bing results index](https://www.bing.com/search?q=IIT+Guwahati+OSINT+Assamese+Facebook+Twitter+YouTube+dataset+github)
- A survey of **82 Hugging Face datasets matching "assamese"** (full API listing) turned up **no author- or user-labelled Assamese text dataset**. The text-bearing ones are monolingual/instruction/ASR corpora, e.g. `MWirelabs/assamese-monolingual-corpus` (1.61M deduplicated sentences, Bengali script, CC BY-SA 4.0; mirrored as `jintz0/assamese-monolingual-corpus`), `marsh-mellow/assamese_wikipedia` (CC BY 4.0), `ffatty/plaintext-wikipedia-full-assamese` (CC BY-SA 3.0), `ananddey/assamese-news-corpus` (1,369 news articles, licence "other"), `ananddey/assamese-wiki-corpus` (~16.5M tokens, CC BY-SA 4.0), `Ranjit89/xahitya-assamese-corpus` (literary text scraped from Xahitya.org, CC0-1.0), `nabakamal/assamese_sentiment` (MIT, 100K–1M rows), `AvinabhDutta-Dev/assamese-movie-reviews-sentiment` (dual-annotated reviews, CC BY 4.0, has DOI) — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)
- An arXiv API query for papers containing both "Assamese" and "authorship" returned **0 results** (`opensearch:totalResults = 0`) — [arXiv API](http://export.arxiv.org/api/query?search_query=all:%22Assamese%22+AND+all:%22authorship%22&max_results=30)

### Inferences
- The "9,730-sample / 16-author Assamese author-attribution corpus" referred to in the assignment is very likely the same resource family as AAALC (16 authors, Gauhati University / Assam Don Bosco University, literary prose). If so, it **is** downloadable — openly, under CC BY 4.0 — but the Mendeley record does not publish the 9,730 figure, so the identification is unconfirmed and should be verified against the Springer chapters before being asserted.
- AssameseBackTranslit is the single most attractive Assamese resource for the stated gap: it is genuinely short, informal, Romanised Assamese from three platforms at 60k sentences. Because it is a *parallel transliteration* resource, author identity was almost certainly never recorded — but the sentences may retain post-level groupings, and the authors (IIT Guwahati — the same institution as the OSINT group, with Sanasam Ranbir Singh as the common name) are the most promising people to approach for a user-ID-preserving release.
- AS-EMO is the closest match in register (Facebook/WhatsApp/YouTube, native + Romanised + code-mixed, emoji) but at 4,502 posts with no author labels it can at best serve for domain-adaptive pre-training of an Assamese short-text encoder, not for verification training.
- Datasets whose text is scraped from bylined sources (`ananddey/assamese-news-corpus`, `Ranjit89/xahitya-assamese-corpus`) could in principle be **re-scraped with bylines retained** to build a weak author-labelled corpus, but the released HF versions carry no author field.

### Gaps
- Could not read the two Springer chapters (paywalled) to confirm corpus sizes, the 9,730-sample figure, author counts or whether a separate download exists.
- The IIT Guwahati OSINT group's resources page is dead; no way to establish what Facebook/X/YouTube collections exist, their sizes, or whether access is by request form.
- AsNER and Assamese UPoS/UD corpora were not reached within the tool budget, so whether they retain source/document metadata is unverified.
- AS-EMO's privacy/anonymisation and dataset-licence sections could not be retrieved.
- Whether the AssameseBackTranslit data is downloadable at all (and under what licence) is unresolved — it would require reading the paper PDF.

## Which Bengali or Indic short-text authorship datasets could serve as transfer or pre-training data?

### Takeaway
The strongest confirmed transfer resource is **BAAD16** — 16 Bangla authors, 17,966 samples, 13.4M+ words, publicly available on Mendeley Data — plus the Hindi–English code-mixed Twitter corpora from IIIT Hyderabad's Precog group for register/script transfer. All confirmed Indic authorship data is long-form literary/blog text; no Indic *short-text, many-author* authorship benchmark was located.

### Cited Findings
- **[TRANSFER] BAAD16 — Bangla Authorship Attribution Dataset**, Mendeley Data: "sample Bangla texts from **16 authors** containing a total of **13.4+ million words**", equally distributed; records indexed from Dec 2019 and Jul 2020. The companion paper reports **17,966 sample texts** across the 16 authors, states the dataset is publicly available, and also releases "six variations of pre-trained language models" for Bangla NLP. Paper: "Authorship Attribution in Bangla Literature (AABL) via Transfer Learning using ULMFiT", accepted ACM TALLIP Aug 2022, DOI 10.1145/3530691; arXiv:2403.05519 (arXiv listing under CC BY 4.0). Reported 99.8% accuracy on BAAD16 with AWD-LSTM/ULMFiT — [arXiv abstract](https://arxiv.org/abs/2403.05519); [Mendeley/Bing index](https://www.bing.com/search?q=Bengali+authorship+attribution+dataset+blog+BAAD16+authors)
- A Bangla NLP resource hub lists an "authorship_attribution" resources page, and GitHub repos `Authorship-Attribution-in-Bangla` and `Authorship-Attribution-using-Transfer…` appear in the same result set (code accompanying the above work) — [Bing results index](https://www.bing.com/search?q=Bengali+authorship+attribution+dataset+blog+BAAD16+authors)
- **[TRANSFER] Hindi–English code-mixed Twitter corpus** (Precog, IIIT Hyderabad): "a unique language tagged and POS-tagged dataset of code-mixed English-Hindi tweets related to five incidents"; hosted at `precog.iiit.ac.in/pubs/twitter_hindi_engli…` as a PDF with the dataset, and indexed in ACL Anthology as "A Twitter Corpus for Hindi-English Code Mixed POS Tagging" — [Bing results index](https://www.bing.com/search?q=code-mixed+Hindi-English+authorship+attribution+dataset+tweets+user+ids)
- **[TRANSFER] HateSpeech-Hindi-English-Code-Mixed-Social-media** (GitHub, `punyajoy/…`) and `anshulwadhawan/emotion_detection` appear as further Hindi–English code-mixed social-media datasets in the same search — [Bing results index](https://www.bing.com/search?q=code-mixed+Hindi-English+authorship+attribution+dataset+tweets+user+ids)
- **[TRANSFER] Bengali–Assamese script overlap**: `anrikus/lexical_diff_bangla_assamese` (+ v2) on Hugging Face document lexical differences between Bangla and Assamese using 1,000 images of parallel Open English Bible text; `promptmafiainc/assamese-bengali-contrastive-eval` provides Assamese–Bengali contrastive artefacts. These bear on how safely Bangla models transfer to Assamese — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)

### Inferences
- BAAD16 is a drop-in pre-training/pre-finetuning source for a Bengali-script authorship encoder, and its script is the same Bengali–Assamese script used by native-script Assamese — but at 16 authors of literary prose it reproduces exactly the register and author-count limits of AAALC. It is useful for representation learning, not for open-set calibration.
- For the Romanised/code-mixed half of the problem, the Hindi–English code-mixed Twitter corpora are the realistic transfer source; however, none of the ones located is described as author/user-labelled, so they would support masked-LM/domain adaptation rather than supervised verification.
- Any Indic authorship verification system built now will most likely have to **construct** its own ≥100-author short-text set (e.g. by re-crawling public posts with user handles under an IRB/consent regime), with BAAD16 + AssameseBackTranslit + AS-EMO used only as pre-training signal.

### Gaps
- Could not confirm BAAD16's exact Mendeley DOI/URL (the record was only visible via a search snippet; the DOI was not retrievable without a further fetch) — this must be looked up before citing.
- PAN shared-task cross-lingual / cross-domain authorship data and FIRE/HASOC Indic code-mixed tracks were **not reached** within the tool budget; no claims are made about them here. Likewise TweetEval and the classic "Blog Authorship Corpus" were not verified in this session.
- No Indian-language SMS or WhatsApp corpus with per-sender labels was located; nothing found confirms one exists publicly.

## Assamese Wikipedia/Wikisource edit histories, blog aggregators, and Q&A sources with per-user text

### Takeaway
Assamese Wikipedia full-history dumps are the one unambiguously legal, openly licensed, per-user Assamese text source available today — they carry a username per revision and are large enough to be interesting, though the register is encyclopedic prose plus talk-page discussion rather than SMS-like chat.

### Cited Findings
- **[ASSAMESE] Assamese Wikipedia (`aswiki`) dumps**, dated 01 Oct 2026, include the full revision history: `aswiki-latest-pages-meta-history.xml.bz2` (~390 MB), the same in 7z (~170 MB), and `aswiki-latest-stub-meta-history.xml.gz` (~51 MB) which holds revision metadata only. Also present: `pages-meta-current.xml.bz2` (~84 MB), `pages-logging.xml.gz` (~9 MB), `user_groups.sql.gz`, and `pages-articles.xml.bz2` (~74 MB) — [Wikimedia dumps](https://dumps.wikimedia.org/aswiki/latest/)
- Two Hugging Face mirrors of Assamese Wikipedia text exist but are article-text-only (no contributor field): `marsh-mellow/assamese_wikipedia` (CC BY 4.0) and `ffatty/plaintext-wikipedia-full-assamese` (CC BY-SA 3.0) — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)
- **[ASSAMESE] Xahitya.org** is the source of `Ranjit89/xahitya-assamese-corpus`, released as CC0-1.0 "literary text scraped from Xahitya.org" — evidence that Assamese literary aggregators are being crawled and that per-author re-crawling is feasible — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)

### Inferences
- `pages-meta-history` gives, per revision, the editor username/IP and timestamp, so diffs can be attributed to accounts and grouped into multiple "sessions" per author — making it the only located Assamese source that satisfies the ≥100-authors-with-multiple-sessions requirement, at the cost of register mismatch. Talk/user-talk namespaces inside the same dump are the most informal Assamese text in it, and are the part worth extracting first.
- Mediawiki licensing (CC BY-SA for text) permits redistribution of derived author-labelled splits with attribution — notably more permissive than anything derivable from Facebook/WhatsApp, whose terms of service and GDPR/India DPDP exposure are the reason no public user-ID-preserving Assamese social corpus exists.

### Gaps
- Assamese Wikisource/Wikibooks dump sizes were not checked (only `aswiki`); an Assamese Reddit/Quora-like Q&A platform with per-user text was not located, and no evidence was found that one exists at usable scale.
- Per-author volume in `aswiki` (how many accounts have ≥N revisions of ≥M words) is unknown without downloading and parsing the stub-history file — a cheap next step (~51 MB).

## Synthetic / augmentation approaches for low-resource authorship

### Takeaway
Nothing specific to author-conditioned generation for low-resource authorship was confirmed in this session; the only relevant released artefacts found are generic Assamese augmentation and transliteration resources.

### Cited Findings
- `amn-raw/assamese-augmented-asr-data` (gated, 100K–1M rows) is an Assamese augmentation dataset, but for ASR rather than text authorship — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)
- AssameseBackTranslit benchmarks ten word-level transliteration models including fine-tuned multilingual transliteration models and two fine-tuned LLMs, with the Neural Transformer best (WER 55.05, CER 19.44, BLEU-4 69.15) — i.e. a usable, evaluated pipeline for *generating* Romanised↔native Assamese variants as augmentation — [ACL Anthology](https://aclanthology.org/2024.lrec-main.143/)
- Large Assamese instruction/synthetic-translation sets exist for pre-training a base LM: `saillab/alpaca_assamese_taco` and `saillab/alpaca-assamese-cleaned` (TaCo paper), `Telugu-LLM-Labs/assamese_alpaca_yahma_cleaned_filtered`, `ananddey/assamese-sft-dataset-v1` (61,929 instruction–response pairs, Apache-2.0), `Tensoic/GPTeacher-Assamese`, and `pritamdeka/assamese-indicxnli-triplet-random-negatives` (100K–1M) / `-10` (1M–10M) plus `KhyontekAI/Assamese-IndicXNLI-Triplet-Random-Negatives` (CC0-1.0, 1M–10M) for contrastive sentence-embedding training — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=100)

### Inferences
- The transliteration direction in AssameseBackTranslit can be inverted to synthesise Romanised variants of any native-script Assamese author-labelled corpus (e.g. AAALC), giving a cheap route to Romanised training data with real author labels — at the risk that model-generated romanisation erases the idiosyncratic spelling choices that are precisely the authorship signal of interest.
- IndicXNLI triplet sets are the obvious warm-start for a contrastive/siamese verification encoder in Assamese before any author-labelled fine-tuning.

### Gaps
- No paper located in this session on author-conditioned generation or synthetic author augmentation for low-resource authorship with released data; the arXiv "Assamese + authorship" query returned nothing, and broader stylometry/augmentation queries were not run within the tool budget. Treat this question as effectively unresearched rather than answered negatively.
