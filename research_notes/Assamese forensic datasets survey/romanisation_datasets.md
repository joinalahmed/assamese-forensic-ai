# Romanised Assamese (and Bengali-script) normalisation / back-transliteration: datasets, lexicons, models

Scope note: everything below was checked against primary pages (GitHub, Hugging Face, ACL Anthology, arXiv, Crossref/OpenAlex metadata) on 2026-10-31. Items marked **[Assamese-specific]** target Assamese directly; items marked **[Transfer: Bengali/Indic]** share the Bengali–Assamese script and are usable only via transfer or fine-tuning. Where a licence or count could not be verified it is listed under Gaps, not guessed. No web-search tool was available in this session, so discovery was done through hub APIs (Hugging Face, Crossref, OpenAlex), arXiv search pages, and direct fetches; the long tail of unindexed Kaggle/university-hosted resources may be under-covered.

## Key question 1 — Other Assamese Roman↔native parallel resources (Dakshina, Aksharantar, IndicXlit, TALLIP 2024 paper, OSINTG data, etc.)

### Takeaway
Beyond AssameseBackTranslit there is exactly one other sizeable Assamese Roman↔native word resource — Aksharantar's 179K Assamese training pairs (mostly machine-mined from IndicCorp, forward-direction, dictionary/corpus register) with a 5,531-pair human test set — and one pretrained model that covers Assamese (IndicXlit, 60.27% top-1 on Aksharantar native Assamese words, 73.38 WER when applied to AssameseBackTranslit). Dakshina does **not** include Assamese; Bhasha-Abhijnaanam has only 512 romanised Assamese sentences (LID test set, but it does carry native+roman sentence pairs); the TALLIP 2024 paper by the same IIT Guwahati group releases no separate dataset.

### Cited Findings

**AssameseBackTranslit / OSINTG-IITG repo [Assamese-specific] — details beyond what the project already uses**
- Repository `osintg-iitghy/LREC-COLING-2024-OSINTG-IITG` is the only public repo of the org; files are `README.md`, `sentence-aligned.txt`, `word-aligned.txt`, `src-{train,dev,test}.txt`, `tgt-{train,dev,test}.txt`; README says "The proper licencing and citation information will be updated after the conference proceedings" — i.e. **no licence file as of 2026-10-31** — [GitHub repo](https://github.com/osintg-iitghy/LREC-COLING-2024-OSINTG-IITG); [org page](https://github.com/osintg-iitghy)
- Line counts measured on download (2026-10-31): `sentence-aligned.txt` 120,628 lines (alternating Roman/native lines → 60,314 sentence pairs); `word-aligned.txt` 527,642 lines (token-level Roman→native pairs, with repeats, i.e. essentially every annotated Assamese token occurrence); `src-train.txt` 45,934, `src-dev.txt` 6,560, `src-test.txt` 13,120 lines — [GitHub raw files](https://raw.githubusercontent.com/osintg-iitghy/LREC-COLING-2024-OSINTG-IITG/main/word-aligned.txt)
- In `sentence-aligned.txt`, the native-script target line keeps English/foreign tokens in Latin script (sample: "ৰৱ ৰৱ বাংলাদেশী বিলাকৰ আৰু কিছু from submit karibo আছে name ৰ লগত …") — so the sentence file is a usable supervision signal for the "leave this token in Roman" decision as well as for back-transliteration — [GitHub raw file](https://raw.githubusercontent.com/osintg-iitghy/LREC-COLING-2024-OSINTG-IITG/main/sentence-aligned.txt)
- Paper statistics (full text): 60,312 sentences; sentence length 1–162 words, mean 11.14 (SD 8.38); average code-mixing 20.1%; 671,921 total words of which 67,131 English, 589,289 Assamese, 15,501 mixed-script tokens; 79,200 unique Assamese words; 65,614 unique transliteration pairs extracted; max 127 Roman variants for one native word; one Roman form maps to up to 31 native words — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf)
- Sources and collection windows (Table 1): Facebook (GU Confession Page, CMO Assam Page) Dec-2013–Feb-2017, 409,168 posts collected / 5,300 annotated / 71,800 Assamese words; YouTube (Dimpu's Vlogs, News Live, Assamese Mixture) Jun-2018–Aug-2023, 385,676 collected / 50,000 annotated / 426,089 words; Twitter (@himantabiswa) Mar–Aug 2021, 285,676 collected / 5,012 annotated / 91,400 words — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf)
- Annotation: 24 annotators + 3 linguist validators; annotators tagged sentence-level language (English / Assamese / Assamese-mixed / Other), back-transliterated Roman Assamese words, retained English-origin words, and flagged named entities; inter-annotator Cohen's κ = 0.83 on the reverse-transliteration task — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf)
- Word-level split 70-10-20: 45,934 train / 6,560 val / 13,120 test unique pairs. Ten word-level systems (Table 3) — WER / CER / BLEU-4: Moses PBSMT 66.78/23.04/64.41; Sequitur joint source-channel 63.99/21.34/67.33; BiLSTM+attention 58.90/19.76/68.60; **Neural Transformer 55.05/19.44/69.15 (best)**; IndicXlit zero-shot 73.38/29.91/54.03; Google Transliteration API 58.79/24.01/67.61; indic-trans 95.11/54.62/24.04; IndicXlit fine-tuned 63.53/21.10/66.48; mT5-small fine-tuned 76.38/31.69/55.50; ByT5-small fine-tuned 66.36/22.94/65.93 — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf)
- Paper itself is CC BY-NC 4.0 (ELRA proceedings footer) — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf); the Anthology landing page lists the abstract (60,312 pairs, Facebook/Twitter/YouTube) — [ACL Anthology](https://aclanthology.org/2024.lrec-main.143/)

**ACM TALLIP 2024 "Transliteration Characteristics in Romanized Assamese Language Social Media Text and Machine Transliteration" [Assamese-specific]**
- Baruah, Singh, Sarmah; ACM TALLIP vol. 23 issue 2, pp. 1–36, published 2024-01-06/08; DOI 10.1145/3639565; closed access (OpenAlex `is_oa: false`, no OA copy) — [Crossref](https://api.crossref.org/works?query=transliteration+characteristics+romanized+assamese&rows=8&select=title,author,container-title,DOI,issued,URL); [OpenAlex record](https://api.openalex.org/works/doi:10.1145/3639565)

- dl.acm.org landing page returned HTTP 403 to automated fetch — [ACM DL](https://dl.acm.org/doi/10.1145/3639565)

**Dakshina (Google) [Transfer: Bengali/Indic] — no Assamese**
- 12 languages: bn, gu, hi, kn, ml, mr, pa, sd, si, ta, te, ur; **Assamese not included** — [GitHub google-research-datasets/dakshina](https://github.com/google-research-datasets/dakshina)
- Per language: romanisation lexicon of 25,000 native word types train + 2,500 dev + 2,500 test (Sindhi 15,000 train), each word type with multiple attested romanisations and attestation counts; 10,000 Wikipedia sentences manually romanised by native speakers with token alignments; native-script Wikipedia text; round-trip CER 3.5–8.5%; licence CC BY-SA 4.0; v1.0 (2020-05-27), repo archived/read-only — [GitHub google-research-datasets/dakshina](https://github.com/google-research-datasets/dakshina)

**Aksharantar (AI4Bharat) [Assamese-specific word pairs + Indic]**
- 26M pairs, 21 languages; Assamese (asm) splits: **179K train / 4K val / 5,531 test**; Bengali 1,231K / 11K / 5,009; licence split by origin: manually collected = CC-BY, mined (Samanantar, IndicCorp) = CC0, existing sources = CC0; HF viewer currently errors (`score` column present only in some files, e.g. not in `asm_train.json`) — [Hugging Face dataset card](https://huggingface.co/datasets/ai4bharat/Aksharantar); file sizes `asm.zip` 4.96 MB, `ben.zip` 33.2 MB — [HF file tree](https://huggingface.co/datasets/ai4bharat/Aksharantar/tree/main)
- Assamese source breakdown (paper Table 1, thousands of unique pairs): existing 0, Wikidata 2, Samanantar-mined 3, **IndicCorp-mined 203**, manually collected 19 → total 217K — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018)
- Assamese test set (Table 2): AK-Freq 1,690 + AK-Uni 1,938 + AK-NEF 742 + AK-NEI 1,161 = 5,531 pairs; mining accuracy on human-judged sample: IndicCorp-asm 0.91, Samanantar-asm 0.93 — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018)
- Manual collection is **forward direction** ("transliterator creates multiple romanized variants for a native word", validated by a checker, via Karya mobile app; 68 annotators) — i.e. annotator-produced romanisations, not organic social-media spellings — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018)
- Assamese unique word list from public corpora used to sample source words: 292K words — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018)

**IndicXlit (AI4Bharat) [Assamese-specific coverage, Indic model]**
- 21 languages incl. Assamese; both Roman→native and native→Roman; 6+6-layer transformer, emb 256, 4 heads, FFN 1024, ≈11M params; trained on Aksharantar; MIT licence; pip `ai4bharat-transliteration`, npm `@ai4bharat/indic-transliterate`, release zips `indicxlit-en-indic-v1.0.zip` / `indicxlit-indic-en-v1.0.zip`; word-level (sentences must be split) — [GitHub AI4Bharat/IndicXlit](https://github.com/AI4Bharat/IndicXlit)
- Reported Roman→native top-1 accuracy, Assamese: AK-Freq 65.95, AK-Uni 55.10, AK-NEF 38.90, AK-NEI 39.16, micro-avg 52.82 (Table 12); Bengali Dakshina 55.49 — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018); README quotes asm 60.27 (native words, En-Indic) and asm 75.55 (Indic-En) — [GitHub AI4Bharat/IndicXlit](https://github.com/AI4Bharat/IndicXlit)
- Re-packaged, dependency-light variants: `Singla0009/all-indic-transliteration` = lossless CTranslate2 FP32 conversion of IndicXlit v1.0, both directions (~45 MB / ~44 MB), MIT, ~1 ms/word CPU, 21 languages incl. `__as__` — [Hugging Face](https://huggingface.co/Singla0009/all-indic-transliteration); `aaiiaxom/indicxlit-roman-to-assamese-onnx-int8` (ONNX int8 Roman→Assamese, tagged phonetic-keyboard/voice-typing) exists on the Hub — [HF models API search "assamese"](https://huggingface.co/api/models?search=assamese&limit=300)

**Bhasha-Abhijnaanam (AI4Bharat) [Assamese + Indic; LID test set but contains parallel sentences]**
- Fields: `native sentence`, `romanized sentence`, `language`, `script`, `source` (sources: Dakshina, Flores-200, "Manually Romanized", "Manually generated"); test sizes native/romanised: **asm 1,012 / 512**, ben 5,606 / 4,595; licence CC0-1.0; not gated; 10.7 MB — [Hugging Face dataset card](https://huggingface.co/datasets/ai4bharat/Bhasha-Abhijnaanam)

**Other Assamese-tagged Hub artefacts**

- HF datasets API search for "assamese" (84 hits) returned **no** dataset explicitly about transliteration, romanisation or code-mixing — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=200)
- Same group (Singh, Sarmah) has a sibling resource for Manipuri: "Insights from Romanized Manipuri Social Media Text: A Transliteration Corpus and Variation Analysis" (Salice, Singh, Sarmah), LREC 2026, DOI 10.63317/3uqwwrf7jvvo — [Crossref](https://api.crossref.org/works?query=romanized+bengali+transliteration+social+media+dataset&rows=10&select=title,author,container-title,DOI,issued,URL)

### Inferences
- The only Assamese word-level lexicon larger than the project's own 65,614 pairs is Aksharantar-asm (≈217K unique pairs incl. test), but ~94% of it is machine-mined from IndicCorp (news register) and the human part is annotator-forward-romanised; its spelling distribution will differ from social-media Roman Assamese, which the LREC paper's IndicXlit zero-shot WER of 73.38 (vs 55.05 for an in-domain transformer) empirically confirms. It is still the best candidate for widening coverage of rarer native words and named entities.
- Fine-tuning IndicXlit on AssameseBackTranslit (setup 8) was *worse* than training a transformer from scratch (63.53 vs 55.05 WER) in the paper, suggesting the gain from Aksharantar pretraining is small at word level; the ceiling the project has hit (in-vocabulary ambiguity, one Roman form → up to 31 native words) needs sentence context, which none of the word-level resources provide — only the project's own `sentence-aligned.txt` (60,314 pairs) and Bhasha-Abhijnaanam's 512 asm sentences do.
- The TALLIP 2024 paper almost certainly re-uses the same OSINTG collection (same three platforms, same authors); its value is analytic (six romanisation schemes, vowel/diacritic mapping tables) rather than as new data.

### Gaps
- TALLIP 2024 full text is paywalled; dataset size, numeric results and any release link could not be verified.
- Whether the OSINTG `word-aligned.txt` carries token-level language tags (English vs Assamese) could not be confirmed from the head of the file; only Roman→native token pairs were observed.
- No "Google/Microsoft transliteration dataset" covering Assamese was found: Google's Dakshina omits Assamese; no Microsoft Indic transliteration dataset page was reachable in this session (Microsoft's Indic transliteration work in Aksharantar is co-authored but hosted by AI4Bharat).
- OSINTG licence remains unspecified (README promises a later update that has not appeared).

## Key question 2 — Bengali Romanised↔native resources usable for transfer (shared script)

### Takeaway
Bengali has a far richer stack: Dakshina-bn (25K-word lexicon + 10K manually romanised sentences, CC BY-SA), Aksharantar-ben (1.23M pairs), BanglaTLit (42.7K social-media back-transliteration pairs + 245.7K romanised-Bangla pretraining corpus, EMNLP Findings 2024), BanglaMix (12,576 YouTube comments, 120,866 token-level LID tags, with Bengali-script transliteration, CC-BY), a 1M-pair Bengali synthetic set (Gharami et al. 2025), and a 207K-word rule-generated Banglish lexicon; several uncurated HF sets (45.7K-row `nahidstaq/bangla-transliteration-data`, 5K-row `SKNahin/bengali-transliteration-data`) have no licence.

### Cited Findings
- **Dakshina Bengali [Transfer]**: bn lexicon 25,000 train / 2,500 dev / 2,500 test native word types with attested romanisations; 10,000 manually romanised Wikipedia sentences with token alignments; CC BY-SA 4.0 — [GitHub dakshina](https://github.com/google-research-datasets/dakshina)
- **Aksharantar Bengali [Transfer]**: 1,231K train / 11K val / 5,009 test; source breakdown (thousands): existing 104, Wikidata 107, Samanantar 193, IndicCorp 1,115, manual 14 = 1,337; existing sources include Dakshina 95K, FIRE-2013 Track 5K, Brahminet 8K — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018); [HF card](https://huggingface.co/datasets/ai4bharat/Aksharantar)
- **BanglaTLit [Transfer]** (Fahim et al., Findings of EMNLP 2024, pp. 14656–14672, DOI 10.18653/v1/2024.findings-emnlp.859): 42.7K romanised-Bangla↔Bangla-script samples plus **BanglaTLit-PT**, a 245.7K-sample romanised-Bangla pretraining corpus; encoders further-pretrained on it reach SOTA on romanised-Bangla classification; code/data at github.com/farhanishmam/BanglaTLit and Anthology attachment `2024.findings-emnlp.859.data.zip`; dataset licence not stated in abstract — [ACL Anthology](https://aclanthology.org/2024.findings-emnlp.859/); [OpenAlex](https://api.openalex.org/works?search=BanglaTLit%20back-transliteration%20romanized%20Bangla&per-page=5)
- Follow-ups trained on BanglaTLit: BanglaFeel (ICCIT 2025, CharCNN+WordLSTM encoder with T5 decoder, BLEU 68.03, closed access); "Robustness of LLMs to Transliteration Perturbations in Bangla" (BLP-2025, code github.com/farhanishmam/BTL-Robustness); BanTH, 37.3K transliterated-Bangla YouTube hate-speech samples (Findings NAACL 2025, arXiv 2410.13281) — [OpenAlex](https://api.openalex.org/works?search=BanglaTLit%20back-transliteration%20romanized%20Bangla&per-page=5)

Computer Science 6(1):69–80, DOI 10.1007/s42044-022-00122-9; closed access; OpenAlex has no abstract, keywords mention WER/BLEU and post-processing; no release info recoverable — [OpenAlex](https://api.openalex.org/works/doi:10.1007/s42044-022-00122-9)

- **Hub Banglish→Bengali models**: `shadabtanjeed/mbart-banglish-to-bengali-transliteration`, `NaheedRayan/banglish_2_bangla_transliteration_model`, `nahidstaq/bangla-transliteration`, `Ana-04/bangla-transliteration-v1`, `syk08/bengali-transliteration`, `DJ2003/my-bengali-transliteration-model`, `Prabuddha14/bn-mni-transliteration-ct2` — [HF models API](https://huggingface.co/api/models?search=transliteration&limit=200); `Khalid751/Banglish-to-Bengali-Transliteration` has inconsistent metadata (Qwen2-VL lineage, unrelated datasets, empty card) and should be treated as unreliable — [HF](https://huggingface.co/Khalid751/Banglish-to-Bengali-Transliteration)
- **FIRE MSIR 2016**: Subtask 1 = Romanised Bengali–English code-mixed question classification; Subtask 2 = Hindi–English tweet retrieval; data emailed only to registered teams; earlier editions covered Hindi, Bangla, Gujarati, Tamil, Kannada, Malayalam — **Assamese never included** — [MSIR 2016 site](https://msir2016.github.io/)

### Inferences
- For transfer, the two cleanest Bengali sentence-level social-media resources are BanglaTLit (42.7K pairs, with repo + Anthology attachment) and BanglaMix (12.6K comments with token LID + transliteration, CC-BY). Both use informal Bangladeshi romanisation conventions (e.g., "valo", "kokhon"), which overlap with but differ from Assamese spellings (Assamese /x/ "xubho", ৰ/ৱ orthography), so they are better as pretraining/initialisation than as direct supervision.
- Dakshina-bn's 10K aligned sentences are the only large, licensed (CC BY-SA), manually romanised Bengali *sentence* corpus; its Wikipedia register is clean but not social-media-like.
- The "Avro-style" phonetic-keyboard corpora asked about do not appear to exist as published datasets; the rule-generated `ShayonSarker` lexicon is the closest analogue (deterministic variants), useful for data augmentation only.

### Gaps
- No published "Avro"/phonetic-keyboard log corpus or "BnTransliteration" dataset was located via HF, arXiv, Crossref or OpenAlex.
- BanglaTLit's own data licence and exact collection sources were not visible on the Anthology abstract page (GitHub repo not fetched).
- Gharami et al. 2025 release location/licence for the 1M Bengali pairs was not verified (arXiv abstract only).
- Shibli et al. 2022 dataset size/release unverified (paywalled).

## Key question 3 — Pretrained multilingual models that handle Romanised Indic input

### Takeaway
IndicXlit (and its CTranslate2/ONNX repacks) is the only openly licensed pretrained transliterator that includes Assamese; RomanSetu provides Llama-2-based LLMs continually pretrained on IndicXlit-romanised text (6 unnamed languages, Llama 2 licence); IndicBERT v2 has **no** romanised variant; general mT5/ByT5 fine-tunes exist on the Hub only for Hindi/Nepali/Sinhala/Darija etc., none for Assamese — and in the LREC paper ByT5-small/mT5-small fine-tunes underperformed a from-scratch transformer on Assamese.

### Cited Findings
- **IndicXlit** — see KQ1; MIT; 21 languages incl. Assamese; ≈11M params; word-level — [GitHub](https://github.com/AI4Bharat/IndicXlit)
- **RomanSetu** (Husain, Dabre, …, Kunchukuttan; ACL 2024; arXiv 2401.14280): continual pretraining of Llama 2 on romanised text (romanised with IndicXlit) then instruction tuning; romanised text "reduces token fertility by 2x-4x"; released HF models `ai4bharat/romansetu-cpt-{roman,native}-{100m…500m}`, `romansetu-base-sft-{native,roman}`, `romansetu-cpt-{native,roman}-sft-*`; CPT data ≈500M words/language; IFT 120K examples/language; **no datasets released**; GitHub repo has no licence file; HF card for `romansetu-cpt-roman-500m` says "6 languages" without naming them, 7B params, Llama 2 licence — [arXiv abs](https://arxiv.org/abs/2401.14280); [GitHub AI4Bharat/romansetu](https://github.com/AI4Bharat/romansetu); [HF model card](https://huggingface.co/ai4bharat/romansetu-cpt-roman-500m)
- **IndicBERT v2** (278M, 23 Indic + English): variants `IndicBERTv2-MLM-only`, `-MLM-Sam-TLM`, `-MLM-Back-TLM`, `IndicBERTv2-SS` (script-unified to Devanagari); **no romanised/Latin-script variant** listed; models MIT, data CC0 — [GitHub AI4Bharat/IndicBERT](https://github.com/AI4Bharat/IndicBERT)
- **IndicLID** (AI4Bharat): two-stage ensemble (fastText + IndicBERT-finetuned), 47 classes = 24 native + 21 Roman + English + other, includes asm_Latn and ben_Latn; romanised accuracy 0.71 (FTR) / 0.80 (full, F1 0.75) at ~10 sent/s, 1.4 GB; native 0.98 F1 at 30K sent/s; MIT; release v1.0 assets include native, roman and "parallel native-roman train pairs" plus the benchmark (asset list failed to load on fetch) — [GitHub AI4Bharat/IndicLID](https://github.com/AI4Bharat/IndicLID); [releases](https://github.com/AI4Bharat/IndicLID/releases)
- **Sangraha synthetic romanised Assamese**: `asm_Latn` split created by translating English WikiMedia into Indic languages and romanising via transliteration; Assamese synthetic = 11,696.4M tokens (native + Latn), Bengali synthetic 13,814.1M; CC-BY-4.0; not gated — [HF ai4bharat/sangraha](https://huggingface.co/datasets/ai4bharat/sangraha)
- **Hub transliteration models (174 for query "transliteration")**: Assamese-tagged = only `jibonChan/assamese-transliteration-lstm` and `Singla0009/all-indic-transliteration` (tags include as, bn); mT5/ByT5 fine-tunes exist for Hindi (`meenakshi16rp/*`), Nepali (`Sobit/mt5-base_ne_en_transliteration`), Sinhala (`RASHINI01/byt5-base-sinhala-*`), Urdu (`ULRs/mt5-large-transliteration-ur`), Darija; Hinglish LLM "UnimeType/Transliteration-2.0-{0.8B,4B}"; multilingual Indic `RakeshBalla/multilingual-transliteration-roman-to-native` (mT5), `ivrsolutions/indic-transliteration` — [HF models API](https://huggingface.co/api/models?search=transliteration&limit=200)
- In the LREC paper, fine-tuned mT5-small (WER 76.38) and ByT5-small (66.36), each run 51 epochs, were worse than the from-scratch transformer (55.05) and even the Google Transliteration API (58.79) on Assamese social-media words — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf)
- Google Research's "Context-aware Transliteration of Romanized South Asian Languages" (Kirov, Johny, Katanova, Gutkin, Roark; Computational Linguistics 2023, DOI 10.1162/coli_a_00510) exists but — like Dakshina on which it builds — does not cover Assamese — [Crossref](https://api.crossref.org/works?query=transliteration+characteristics+romanized+assamese&rows=8&select=title,author,container-title,DOI,issued,URL)

### Inferences
- IndicXlit is the only off-the-shelf transliterator with Assamese; its CT2/ONNX repacks make it cheap to use as a candidate generator (n-best via beam 4) to feed a sentence-level reranker, which is where the project's ambiguity ceiling lies.
- RomanSetu's romanised-Indic LLMs are the only pretrained LMs exposed to romanised Indic text at scale, but with Llama 2 licence, unnamed language set and 7B size they are heavy for a normaliser; also their romanisation is IndicXlit-synthetic, not organic social-media spelling.
- IndicTrans2 "romanised variants" asked about in the brief do not exist as released models; the romanised-input direction in the AI4Bharat ecosystem is RomanSetu.

### Gaps
- RomanSetu's exact six languages (whether Assamese or Bengali is among them) could not be confirmed from abstract, GitHub README or HF card; full paper PDF not fetched.
- No "IndicBERT v2 with romanised data" model was found; if one exists it is not in the IndicBERT repo README.
- IndicLID "parallel native-roman train pairs" sizes per language unknown (release asset list did not load).

## Key question 4 — Word-level LID datasets for Assamese–English–Hindi code-mixed Romanised text

### Takeaway
No openly downloadable word-level LID dataset for Romanised Assamese–English–Hindi exists; the only published work (Sarma, Singh, Goswami, IALP 2018, Assamese–Bengali–Hindi–English Facebook messages) releases no data, FIRE/ICON shared tasks never included Assamese, and the newer ACE-Mix (Laskar 2024) gives no size or distribution details. The practical LID resources are Bhasha-Abhijnaanam/IndicLID (sentence-level, 512 asm_Latn test sentences) and the implicit token-level signal in the project's own AssameseBackTranslit sentence file (English kept in Latin, 67,131 English tokens).

### Cited Findings
- "Word Level Language Identification in Assamese-Bengali-Hindi-English Code-Mixed Social Media Text" (Sarma, Singh, Goswami), IALP 2018, pp. 261–266, DOI 10.1109/ialp.2018.8629104: corpus of "transliterated Assamese-Bengali-Hindi-English messages collected from Facebook"; finds global semantic similarity helps identify borrowed words and local context disambiguates words valid in several languages; **no dataset size, no release**; closed access — [OpenAlex](https://api.openalex.org/works/doi:10.1109/ialp.2018.8629104); [Crossref](https://api.crossref.org/works?query=assamese+english+code-mixed+language+identification+social+media&rows=10&select=title,author,container-title,DOI,issued,URL)
- "BERT Based Language Identification in Code-Mixed English-Assamese Social Media Text" (Kalita, Deka, Chennareddy, Sarma), Springer AIS 2023, pp. 173–181, DOI 10.1007/978-981-99-1620-7_14; closed access; no abstract indexed; no availability info — [OpenAlex](https://api.openalex.org/works/doi:10.1007/978-981-99-1620-7_14)
- "ACE-Mix: A Dataset for Assamese-English Code-Mixed Language Processing" (Afsana Laskar, Gauhati Univ.), Journal of Electrical Systems, 2024-04-25, OA CC-BY-ND PDF at journal.esrgroups.org/jes/article/download/8293/5596; abstract gives **no size, annotation scheme or distribution** details; companion POS-tagging paper (XLM-R+CRF) by same author; journal not in DOAJ — [OpenAlex](https://api.openalex.org/works?search=ACE-Mix%20Assamese-English%20code-mixed&per-page=3); [OpenAlex search](https://api.openalex.org/works?search=Assamese%20code-mixed%20transliteration%20dataset&per-page=10&filter=publication_year:2020-2026)
- Nath et al. 2025 (Social Network Analysis and Mining 16(1), DOI 10.1007/s13278-025-01531-x) extend a Kaggle Assamese hate-speech corpus with code-mixed and transliterated examples; GPT-4 macro-F1 0.870; no size — [OpenAlex search](https://api.openalex.org/works?search=Assamese%20code-mixed%20transliteration%20dataset&per-page=10&filter=publication_year:2020-2026)
- FIRE MSIR 2016 languages: Bengali–English (Subtask 1) and Hindi–English (Subtask 2); registration-only data distribution; Assamese not in any edition named — [MSIR 2016](https://msir2016.github.io/)
- AssameseBackTranslit annotators labelled sentence-level language (English / Assamese / Assamese-mixed / Other) and retained English-origin words in Roman script; 67,131 English + 15,501 mixed-script tokens among 671,921 — [ACL Anthology PDF](https://aclanthology.org/2024.lrec-main.143.pdf); the released `sentence-aligned.txt` target side keeps English tokens Latin — [GitHub raw](https://raw.githubusercontent.com/osintg-iitghy/LREC-COLING-2024-OSINTG-IITG/main/sentence-aligned.txt)
- Bhasha-Abhijnaanam: 512 romanised Assamese + 1,012 native Assamese test sentences, 4,595 romanised Bengali; sentence-level labels only; CC0 — [HF](https://huggingface.co/datasets/ai4bharat/Bhasha-Abhijnaanam)
- BanglaMix (Bengali–English) is the closest token-level LID dataset in the script family: 120,866 tokens with BAN/ENG/ROM_BAN/OTHER/UNK tags, CC-BY — [OpenAlex](https://api.openalex.org/works/doi:10.1016/j.dib.2026.113317)
- Hub LID artefacts for Assamese are image-based script discriminators (`anrikus/lexical_classifier_bangla_assamese_v2`) or speech dialect classifiers, not Roman-text token LID — [HF models API](https://huggingface.co/api/models?search=assamese&limit=300)

### Inferences
- A token-level Roman-Assamese/English/Hindi LID set can be derived from AssameseBackTranslit itself: any token whose target remains Latin is "keep", any token whose target is Bengali-script is "transliterate"; the observed sample shows Hindi tokens (e.g. "karibo") sometimes left Latin, so Hindi handling in the gold data is inconsistent and would need auditing before use as LID gold.
- IndicLID's romanised LID (0.80 accuracy, sentence-level) is too coarse for per-token decisions but usable as a sentence-level prior (e.g., hin_Latn vs asm_Latn posts).

### Gaps
- No public Assamese–English–Hindi word-level LID gold set with licence was found; the IALP 2018 and Kalita 2023 datasets appear unreleased.
- ACE-Mix size and distribution unknown (PDF not read).
- ICON shared-task pages (2015/2016 code-mixed POS/LID) were not fetched; from memory of their published language lists they covered Bengali/Hindi/Telugu–English, not Assamese, but this was not re-verified in this session.

## Key question 5 — Monolingual native-script Assamese corpora for a word-level LM

### Takeaway
Native-script Assamese text available openly totals roughly a few hundred million real tokens: Sangraha verified 292.1M + unverified 17.5M tokens (CC-BY-4.0), IndicCorp v2 3.38M lines (CC0), OSCAR 23.01 24.4M words (gated), CC-100 7.6 MB, MWirelabs 77.4M tokens / 1.61M sentences (CC BY-SA 4.0), Assamese Wikipedia 26,021 articles; mC4 has no Assamese; Sangraha's 11.7B-token Assamese "synthetic" split is machine-translated Wikipedia (native + romanised) and should be treated as such.

### Cited Findings
- **Sangraha** (AI4Bharat, IndicLLMSuite, arXiv 2403.06350): Assamese verified 292.1M tokens, unverified 17.5M, synthetic 11,696.4M (total 12,006.0M); Bengali 10,604.4M / 5,608.8M / 13,814.1M; verified = human-verified websites + OCR of Indic PDFs + transcriptions; unverified = perplexity-filtered multilingual crawls; synthetic = English WikiMedia translated into 14 languages then romanised (both `asm_Beng` and `asm_Latn`); CC-BY-4.0; no gating; parquet via `data_dir="verified/asm"` — [HF ai4bharat/sangraha](https://huggingface.co/datasets/ai4bharat/sangraha)
- **IndicCorp v2**: `asm_Beng` 3.38M rows; `ben_Beng` ≈29.6M rows; total ≈481M rows, 275 GB, 20.9B tokens / 24 languages; CC0; not gated; Assamese preview is predominantly news — [HF ai4bharat/IndicCorpV2](https://huggingface.co/datasets/ai4bharat/IndicCorpV2); [GitHub IndicBERT](https://github.com/AI4Bharat/IndicBERT)
- **OSCAR 23.01**: as = 89,542 documents, 24,395,215 words, 412.1 MB; bn = 3,474,086 docs, 1,092,983,765 words, 19.1 GB; access depends on user status (request-based), licence not stated on version page — [OSCAR 23.01](https://oscar-project.github.io/documentation/versions/oscar-2301/)
- **CC-100**: as 7.6 MB, bn 860 MB, bn_rom 164 MB; no as_rom — [data.statmt.org/cc-100](https://data.statmt.org/cc-100/)
- **mC4 (allenai/c4 multilingual)**: 108 language codes; **'as' absent**, 'bn' present (~7.44M rows); ODC-BY plus Common Crawl terms — [HF allenai/c4](https://huggingface.co/datasets/allenai/c4)
- **Assamese Wikipedia**: 26,021 content articles, 128,389 total pages, 648,410 edits (2026-10-31) — [as.wikipedia Special:Statistics](https://as.wikipedia.org/wiki/Special:Statistics)
- **MWirelabs/assamese-monolingual-corpus**: 1,613,879 sentences, 77,427,585 IndicBERTv2 tokens, ~655 MB CSV; sources IITB-IndicMonoDoc, Samanantar (Assamese side), poetry and civic texts; 7-step cleaning (script filter ≥50% Bengali-script chars, dedup removed 496,008 lines); CC BY-SA 4.0 — [HF](https://huggingface.co/datasets/MWirelabs/assamese-monolingual-corpus)
- Other HF Assamese text sets: `marsh-mellow/assamese_wikipedia`, `ffatty/plaintext-wikipedia-full-assamese`, `ananddey/assamese-news-corpus` (1,369 articles), `Ranjit89/xahitya-assamese-corpus`, `jintz0/assamese-monolingual-corpus` (duplicate of MWirelabs) — [HF datasets API](https://huggingface.co/api/datasets?search=assamese&limit=200)
- `Ranjit89/Assamese-Text-Dataset-45T-Tokens` hosts only 491 rows; its "45.3T tokens" claim refers to an off-page archive and is internally incoherent (e.g., IndicCorp v2 listed at 37.8T) — treat as unreliable; self-declared CC0 over third-party news/lyrics — [HF](https://huggingface.co/datasets/Ranjit89/Assamese-Text-Dataset-45T-Tokens)
- Aksharantar authors extracted a 292K-word unique Assamese word list from public corpora (IndicCorp) when sampling words for annotation — a rough indication of the native-script vocabulary size available — [arXiv 2205.03018 PDF](https://arxiv.org/pdf/2205.03018)
- Native-script Assamese LMs on the Hub usable as rerankers: `l3cube-pune/assamese-bert`, `MWirelabs/assamese-roberta` (~0.1B, trained on the MWirelabs corpus), `pritamdeka/muril-base-cased-assamese`, `pritamdeka/mDeBERTa-v3-base-Assamese`, `BharatVLM/AssameseGPT2`, `tamang0000/tinyllama-assamese-*`, `tamang0000/Qwen2-0.5b-assamese-*`, `KhyontekAI/gemma-4-E4B-it-Assamese-Updesh` — [HF models API](https://huggingface.co/api/models?search=assamese&limit=300)

### Inferences
- Sangraha-verified (292M tokens, CC-BY) plus IndicCorp v2 asm (CC0) is the practical core for a word-level native-script LM; adding MWirelabs risks duplication with Samanantar/IndicCorp content. Register is overwhelmingly news/formal, so a social-media-style LM would still rely on the native side of AssameseBackTranslit (589K Assamese tokens) for domain adaptation.
- Sangraha's `asm_Latn` synthetic split (IndicXlit-romanised translated Wikipedia) is the only billion-token-scale romanised Assamese text in existence; it reflects IndicXlit's canonical spellings rather than user variation, so it is suitable for pretraining a romanised encoder but not for learning the spelling distribution of real posts.

### Gaps
- Sangraha's split between `asm_Beng` and `asm_Latn` token counts within the 11.7B synthetic total was not shown on the card.
- OSCAR's current licence/terms page was not fetched; access is request-based.
- Exact token counts for IndicCorp v2 Assamese (only row counts shown) were not available.
